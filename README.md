A from-scratch chess engine in 2,823 bytes of Python — 0x88 board, alpha-beta with transposition table, killers, history and quiescence, iterative deepening to depth 8 with a fixed 60,000-node budget, deterministic, stdlib only.

## Run it

```sh
python3 main.py
```
